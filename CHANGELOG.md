# Changelog

## 0.1.5 — 2026-11-14

### PHP 8.5

- Убраны вызовы `imagedestroy()` при конвертации в WebP: с PHP 8.0 функция no-op, на 8.5 давала Deprecated и ломала JSON-ответ аплоада в галерею.

## 0.1.4 — 2026-11-14

### Документация

- Убраны упоминания конкретных сайтов из README, админки и примеров.
- Пример настроек: `examples/settings.example.json`.

## 0.1.3 — 2026-11-14

### CI

- Фикстура PNG в тестах создаётся через GD (без обязательного ImageMagick CLI).
- В workflow релиза установлен пакет `imagemagick` как запасной драйвер WebP.

## 0.1.2 — 2026-11-14

### CI

- Workflow релиза выровнен с `blog`: тесты на ядре 0.8.5, `./release.sh`, публикация zip в GitHub Release.

## 0.1.1 — 2026-11-14

### Репозиторий обновлений

- В `plugin.json` указан `repository`: `burzilov/motorchk-plugin-catalog` для автообновлений из GitHub Releases.

## 0.1.0 — 2026-11-14

### Первый релиз

- Галерея страницы в редакторе ядра: загрузка с конвертацией в WebP (большой и `-sm`), порядок перетаскиванием, главный кадр, удаление из `images:` (файлы на диске — только по явному флагу).
- Доска раздела: группы (`group`) и порядок (`order`), DnD внутри ряда и между рядами, создание черновика, публикация.
- Настраиваемые поля карточек в `settings.json` (типы text/textarea/number/url/select/checkbox, подписи RU/EN). Встроенных полей под клиента нет.
- Требует ядро `>=0.8.5` (`page_fields`, `pages()->updateMeta`).
- Обработка изображений: PHP GD+WebP или ImageMagick (`magick`/`convert`).
